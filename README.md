**AI-powered customer support platform that automates ticket triage, suggests responses, and helps support teams work smarter.**

---

## 🚀 Features

- 🔍 Automated ticket classification
- 💬 AI-suggested replies
- 📊 Dashboard for agent performance
- 🧠 Learns from historical support data

---

## 🛠 Tech Stack

- **Backend**: Python 3.11, FastAPI
- **Frontend**: React 18, Material UI
- **AI/ML**: OpenAI GPT-4, LangChain
- **Database**: SSMS 

---

## 🧪 Setup Instructions

```bash
# Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

# Frontend
cd frontend
npm install
npm run dev
